Простой калькулятор с построчным вводом в консоль простых выражений. Калькулятор поддерживает: числа целые или дробные (разделители . или ,), операторы +, -, *, / с поддержкой унарного минуса и множественно вложенные скобки. 
Проект использует не самый эффективный метод, но сильных проблем в оптимизации нет.
